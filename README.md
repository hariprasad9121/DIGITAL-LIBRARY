# Library Management System

A full-featured **Library Management System** built using **Flask (Python)** and **SQLite**, designed to manage book transactions for both students and admins. This system provides a user-friendly interface with real-time profile data fetching, dynamic book management, and secure login functionality.



## Features

###  Student Dashboard
- Login/Registration with email and password
- Dynamic profile display fetched from database using session email
- Add, update, delete, and search books taken from the library
- Track borrow date and update return date
- Delete entries upon book return
- Internal CSS + Bootstrap for clean UI

### Admin Dashboard
- Manage books (add, update, delete)
- View all student book transactions
- Manage student/member accounts

### Authentication
- Session-based login
- Password encryption & validation
- Unique email check during registration
